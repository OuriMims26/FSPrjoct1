# המטבח שלנו

אתר מתכונים סטטי בעברית (HTML ו-CSS). לפתיחה לוחצים פעמיים על index.html.

קבצים עיקריים:
- index.html - דף הבית
- recettes.html - גלריית המתכונים, טבלת השוואה, חוברת PDF ומתכונים מלאים
- about.html - עמוד עלינו, נגן אודיו, מפה וטופס יצירת קשר
- css/style.css - עיצוב משותף (Flexbox, Grid והתאמה למסכים קטנים)
